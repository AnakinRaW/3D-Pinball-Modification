# PCB

Custom circuit boards for the modification: schematics, layouts, and the fabrication outputs generated from them.

Designed in **EasyEDA**, working from local project files kept in this repository. Each board gets its own directory containing the EasyEDA project, a schematic PDF so the design can be read without installing EasyEDA, and a `fab/` directory with the Gerber, drill, pick-and-place and BOM files sent to the manufacturer.
