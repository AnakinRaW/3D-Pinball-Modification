# Assets

Photos of the build, renders, and diagrams used in the documentation.

[`media.md`](media.md) gives how a game's pictures, videos and sounds are made. [`playfield/`](playfield/) holds the vector drawing of the machine, composed from one file per part by [`tools/playfield/compose.py`](../tools/playfield/compose.py). [`intro/`](intro/) holds the machine's intro film with its sound, and the scripts that build both. [`sounds/`](sounds/) holds the sound sources that the intro and the trailer mix their tracks from.
